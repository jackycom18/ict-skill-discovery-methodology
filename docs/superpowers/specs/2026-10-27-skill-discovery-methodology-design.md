# 华为云技能发现与 VOD 反馈方法设计

> 目标判据：华为 ICT 1.9 实验手册和“只使用免费资源”的约束。

## 目标

基于官方 `huawei-cloud-find-skills` 与 `huawei-cloud-vod-collector` 技能，完成一次“意图检索 → 技能确认 → 缺口判断 → VOD 问题单”的只读实践，并输出可复用的方法论。

## 实践场景

目标意图：查找查询华为云 ECS、BMS、IMS、AS 等计算资源的技能，并判断它是否覆盖 CCE 云容器引擎。

## 流程

1. 用中文/英文关键词调用 find-skills。
2. 阅读命中技能的描述、触发词、依赖和参数。
3. 判断技能是否满足目标意图。
4. 若存在能力缺口，调用 vod-collector 生成结构化 VOD。
5. 对问题单脱敏，保留现象、影响、期望、复现和优先级。
6. 将流程整理为方法论，形成可发布文章。

## 安全与费用

- 只执行只读索引查询和本地文件操作。
- 不创建云资源，不调用计费 API。
- 不提交 GitCode Token、AK/SK 或个人信息。
- 不自动授权第三方 OAuth；如需真实投递 VOD，由用户在客户端完成授权。

## 产物

- 官方 find-skills 与 vod-collector 技能副本。
- 技能搜索结果。
- 一份本地 VOD 问题单。
- `METHODOLOGY.md`：标准化方法论文档。
- README、项目备忘和代码地图。
